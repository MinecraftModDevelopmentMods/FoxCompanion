# Fox Companion

Fox Companion is a NeoForge mod project for fox companion gameplay. This
initial Minecraft 26.3 build establishes the development, validation, and
release scaffold; it does not add gameplay content yet.

Version `0.1.0.2603002` targets Minecraft 26.3, NeoForge 26.3.0.23-beta, and
Java 25. Installable gameplay releases will be documented here after their
behavior has been designed, implemented, and tested.

## Development

See [Development](docs/DEVELOPMENT.md) for the supported toolchain and local
verification gates. See [Release process](docs/RELEASE-PROCESS.md) for the
