# NeoForge MDK baseline

The initial scaffold was derived from the official NeoForge 26.3 NeoGradle
MDK repository:

- repository: `https://github.com/NeoForgeMDKs/MDK-26.3-NeoGradle`;
- source commit: `fe95c10fa47acfa18ef01976a82c090654e04aa7`;
- NeoForge: `26.3.0.23-beta`;
- NeoGradle userdev: `7.1.39`;
- Gradle wrapper: `9.2.1`;
- Java: `25`.

Only the official Gradle wrapper and target-native build conventions were used.
The MDK example mod, example configuration, assets, metadata, README, and
template license are not part of Fox Companion.

A NeoForge installer is a packaged client/server installer. It must not be
unpacked over a development checkout or substituted for the NeoGradle MDK.
